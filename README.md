# متجر تكوين 🛍️

> **ملاحظة:** المتجر الرئيسي في جذر المستودع الآن هو **لينا تيك** (انظر القسم الأخير). متجر تكوين انتقل إلى مجلد `takween/` وكل ما في هذا القسم ينطبق على ملفات ذلك المجلد.

متجر إلكتروني عربي بسيط وسريع، يعمل بدون سيرفر أو قاعدة بيانات، ويستقبل الطلبات عبر **واتساب**.

## المميزات
- واجهة عربية كاملة (RTL) ومتجاوبة مع الجوال
- تصنيفات وبحث فوري في المنتجات
- نافذة تفاصيل المنتج مع اختيار الكمية
- سلة تسوق محفوظة في المتصفح
- حساب الشحن تلقائياً مع شحن مجاني فوق مبلغ معيّن
- إتمام الطلب بنموذج بيانات العميل، ثم إرسال الطلب كاملاً إلى واتساب

## التخصيص
كل الإعدادات في ملف واحد: **`js/config.js`**
- `STORE`: اسم المتجر، الشعار النصي، العملة، **رقم الواتساب**، البريد، إنستغرام، رسوم الشحن.
- `CATEGORIES`: التصنيفات.
- `PRODUCTS`: المنتجات. لكل منتج: `name`, `category`, `price`, `oldPrice` (اختياري)، `desc`, `badge` (اختياري)، و`image` (رابط صورة، أو مسار مثل `images/oud.jpg`). بدون صورة تُعرض `emoji` بخلفية من اللون `color`.

الألوان في أعلى ملف `css/style.css` (متغيرات `:root`).

## التشغيل محلياً
```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## النشر مجاناً على GitHub Pages
1. ادمج هذا الفرع في `main`.
2. من إعدادات المستودع: **Settings → Pages**.
3. اختر **Deploy from a branch** ثم `main` و `/ (root)` واحفظ.
4. سيصبح متجر لينا تيك متاحاً على `https://<اسم-المستخدم>.github.io/takween-store/` ومتجر تكوين على `/takween-store/takween/`.

## ✦ لينا تيك — المتجر الرئيسي
متجر إكسسوارات تقنية فاخرة بثيم أسود وذهبي، يعمل بدون سيرفر ويستقبل الطلبات عبر واتساب.

**المميزات:** ٢٠ منتجاً في ٦ أقسام · بحث وترتيب (الأكثر طلباً، الأحدث، السعر) · نافذة منتج بخيارات اللون/المقاس والمواصفات · سلة محفوظة مع شريط تقدّم للشحن المجاني · أكواد خصم · نموذج طلب مع اختيار طريقة الدفع ورقم طلب · إرسال الطلب أو نسخه لواتساب · أسئلة شائعة · زر واتساب عائم · متجاوب مع الجوال.

**التعديل** — كل شيء في `js/config.js`:
- `STORE`: الاسم، **رقم الواتساب**، البريد، إنستغرام، تيك توك، المدينة، رسوم الشحن، حد الشحن المجاني، طرق الدفع.
- `COUPONS`: أكواد الخصم (حالياً `LINA10` و `VIP15`).
- `CATEGORIES` و `PRODUCTS`: الأقسام والمنتجات. لكل منتج `finishes` (الخيارات) و `specs` (المواصفات) و `badge` اختياري.
- **الصور:** المنتجات تُعرض برسومات خطية ذهبية من `js/icons.js`. لاستخدام صورة حقيقية أضف للمنتج `image: "images/case.jpg"` (يفضّل صور مربعة بخلفية داكنة).
- `FAQ`: الأسئلة الشائعة.

الألوان والخطوط في أعلى `css/style.css`. الرابط القديم `/lina-tech/` يحوّل تلقائياً للمتجر الرئيسي.
