# لوحة التكاليف الشهرية لإصلاح الآليات

لوحة تحليلية تفاعلية (ملف HTML واحد) للتكاليف الشهرية للإدارة العامة للصيانة.

- `index.html`: افتحه مباشرة في المتصفح. يحتوي على بيانات محرم وصفر 1448هـ (تفصيلي) وربيع الأول 1448هـ (ملخص مناطق).
- `نموذج_تكاليف_الصيانة_الشهرية.xlsx`: نموذج التعبئة الشهري (متاح أيضاً من زر "تحميل نموذج Excel" داخل اللوحة).

## إضافة شهر جديد
1. حمّل النموذج وعبّئ الشهر والسنة وسطراً لكل آلية (النوع، اللوحة، المنطقة، الإصلاح، القيمة).
2. (اختياري) عبّئ ورقة "الآليات المتعطلة".
3. اضغط "رفع ملف شهري" واختر الملف، راجع المعاينة ثم "إضافة إلى التحليل".

تقبل اللوحة أيضاً ملفات "بيان الآليات الجاهزة" بصيغتها القديمة وتقارير الملخص حسب المنطقة. البيانات المرفوعة تحفظ في متصفح المستخدم فقط.
